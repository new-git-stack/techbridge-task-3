Program 1 · Working with data and extracting insights

Data Analytics

This program introduces you to practical data analysis. You will work with real datasets, learn to clean and prepare them, and present what you find in a way that supports business decisions.

Skills you will develop

  • Spreadsheet analysis
  • Data cleaning
  • SQL
  • Data visualization
  • Business-focused analysis

Good fit if you: enjoy finding patterns, asking questions of data, and explaining what the numbers mean.

Program 2 · Designing and building websites and web applications

Web Development

This program introduces you to practical website development. You will build web projects, host them online, and learn the tools developers use to manage and share their code.

Skills you will develop

  • HTML
  • CSS
  • JavaScript
  • Git/GitHub
  • Building web projects

Good fit if you: like making things people can see and use, and want a portfolio of real projects.
