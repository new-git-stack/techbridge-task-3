TechBridge Internship

Your 30-day internship journey

TechBridge provides a structured 30-day practical internship made up of 8 tasks. Participants progressively develop their web development skills by completing practical projects, and each task is a step up from the last.

The 8 tasks

Select a task to see what you will build. The bar under each task fills up as the work gets more challenging, from Beginner to Advanced Beginner.

Task 1 Day 1 Build the TechBridge Homepage

Day 1 of 30 · Level: Beginner

Create the first version of the TechBridge website using HTML and CSS.

Task 2 Day 4 Build the TechBridge Programs Experience

Day 4 of 30 · Level: Beginner

Create a Programs experience that presents TechBridge's available learning programs.

Task 3 Day 8 Build the Internship Tasks Experience

Day 8 of 30 · Level: Beginner → Intermediate

Create an interface that presents the TechBridge internship tasks and helps users understand the internship journey.

Task 4 Day 11 Build an Interactive Task Tracker

Day 11 of 30 · Level: Beginner → Intermediate

Use JavaScript to make the internship task experience interactive and allow progress to be tracked.

Task 5 Day 15 Build the Intern Registration Experience

Day 15 of 30 · Level: Intermediate

Create a professional registration and onboarding interface for TechBridge interns.

Task 6 Day 19 Build the Task Submission System

Day 19 of 30 · Level: Intermediate

Create an interface through which interns can prepare and submit their task work.

Task 7 Day 22 Build the Intern Dashboard

Day 22 of 30 · Level: Intermediate → Advanced Beginner

Create a dashboard where an intern can view their profile, progress, tasks, and submissions.

Task 8 Day 26 Build the Complete TechBridge Internship Platform

Day 26 of 30 · Level: Intermediate → Advanced Beginner

Combine the different components created during the internship into a complete TechBridge platform.
